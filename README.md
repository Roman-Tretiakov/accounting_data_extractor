# accounting_data_extractor

Программа запускается из папки, в которой лежат входные файлы `contracts.csv`, `works.csv` и `payments.csv`. Если какого-либо файла нет, приложение до запроса параметров отчёта выведет ошибку с именами недостающих файлов. Файл результата `result_accouting.csv` также создаётся в текущей папке.

Для запуска исходного TypeScript-скрипта требуется Node.js 22.6 или новее. Например, чтобы использовать тестовые данные проекта:

```powershell
Set-Location .\test_task_data
node --experimental-strip-types ..\src\index.ts
```

Сборка автономного Windows x64 `.exe` из корня проекта (Node.js на компьютере пользователя не требуется):

```powershell
npm install
npm run build:exe
```

После сборки перейдите в папку с тремя CSV-файлами и запустите exe. Например, для тестовых данных проекта:

```powershell
Set-Location .\test_task_data
..\dist\accounting_data_extractor.exe
```

Для другого набора данных запустите exe по его пути из нужной рабочей папки. Программа запросит отчётную дату и способ вывода; при выборе CSV сохранит результат в текущей папке. Если `result_accouting.csv` уже существует, программа спросит подтверждение замены.

Запуск проверок из корня проекта:

```sh
npm test
```
